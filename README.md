# Montaña Serena 🌿

**Proyecto académico de desarrollo web y práctica de Git y GitHub**

## 1. Descripción del proyecto

Montaña Serena es un sitio web de demostración orientado a la presentación de alojamientos de montaña en El Salvador. Su propósito es mostrar las opciones de hospedaje, las experiencias disponibles y un formulario demostrativo para consultar reservas.

Este proyecto se utiliza como ejemplo práctico para aplicar el control de versiones mediante Git y la gestión de repositorios remotos con GitHub.

## 2. Objetivos

### Objetivo general

Documentar y demostrar el uso de Git y GitHub como herramientas para el control de versiones y la colaboración en un proyecto de desarrollo web.

### Objetivos específicos

- Identificar la estructura y los archivos que conforman el proyecto.
- Comprender cómo registrar cambios mediante commits.
- Explicar el proceso de publicación de archivos en un repositorio remoto.
- Practicar el seguimiento del historial de cambios.
- Promover la organización y documentación del trabajo colaborativo.

## 3. Tecnologías utilizadas

- **HTML5:** define la estructura y el contenido de la página web.
- **CSS3:** establece los estilos, la distribución y el diseño adaptable.
- **JavaScript:** permite incorporar interactividad y comportamientos dinámicos.
- **Git:** permite registrar y administrar las versiones del código.
- **GitHub:** aloja el repositorio remoto y facilita la colaboración.

## 4. Estructura del repositorio

| Archivo | Descripción |
|---|---|
| `index.html` | Contiene la estructura principal del sitio web. |
| `style.css` | Define los estilos visuales y la adaptación a diferentes pantallas. |
| `script.js` | Contiene el código JavaScript para las interacciones de la página. |
| `README.md` | Documenta el proyecto, sus tecnologías y su ejecución. |

## 5. Aplicación de Git y GitHub

Git permite llevar un registro de las modificaciones realizadas en los archivos del proyecto. GitHub permite almacenar el repositorio de forma remota y compartir el código con los integrantes del equipo.

Los principales comandos que pueden utilizarse en este proyecto son:

### Consultar el estado de los archivos

```bash
git status
```

Permite identificar archivos modificados, archivos nuevos y cambios preparados para registrarse.

### Preparar los cambios

```bash
git add .
```

Agrega los cambios del directorio actual al área de preparación de Git.

### Registrar una versión

```bash
git commit -m "Documenta el proyecto Montaña Serena"
```

Guarda los cambios preparados en el historial local del repositorio.

### Consultar el historial

```bash
git log --oneline
```

Muestra un resumen de los commits registrados.

### Publicar los cambios en GitHub

```bash
git push
```

Envía los commits locales a la rama remota configurada, siempre que exista la configuración necesaria y se cuente con los permisos correspondientes.

## 6. Flujo de trabajo aplicado

El flujo de trabajo propuesto para el proyecto consiste en:

1. Crear o modificar los archivos del sitio web.
2. Revisar el estado de los cambios con `git status`.
3. Preparar los archivos mediante `git add`.
4. Registrar una versión con `git commit`.
5. Publicar los cambios en GitHub mediante `git push`.
6. Verificar en el repositorio remoto que los cambios se hayan publicado correctamente.

## 7. Ejecución del proyecto

Para visualizar el sitio web:

1. Clonar o descargar el repositorio.
2. Mantener `index.html`, `style.css` y `script.js` en la misma carpeta.
3. Abrir `index.html` en un navegador web.
4. Verificar la navegación y las secciones de la página.


## 8. Conclusión

El proyecto Montaña Serena constituye un ejemplo práctico para comprender la utilidad de Git y GitHub en el desarrollo web. El control de versiones permite mantener un historial de cambios, mientras que el repositorio remoto facilita el almacenamiento, la consulta y la colaboración sobre los archivos del proyecto.

La documentación del repositorio contribuye a mejorar su organización y facilita que otros integrantes comprendan su estructura y funcionamiento.
